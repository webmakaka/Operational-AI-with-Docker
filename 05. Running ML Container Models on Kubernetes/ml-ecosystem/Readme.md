
| Tool | Problem it solves/Reach for it when ... |
| :--- | :--- |
| **KubeRay** | You need distributed training or serving with Ray, running fine-tuning jobs across multiple GPUs, hyperparameter search, or Ray Serve for advanced model routing. |
| **Kubeflow Pipelines** | You want to automate the full training lifecycle. Reproducible pipelines that ingest data, preprocess, train, evaluate, and promote are triggered on a schedule or on demand. |
| **KServe** | You're serving multiple models or need scale-to-zero. Manage a fleet of different model types from a single endpoint or cut GPU costs during off-peak hours. |
| **MLflow** | You need to track experiments and register models. The moment you run more than one training experiment, MLflow saves you from losing track of what worked and why. |
